# Yeast Gene Selection & Dataset Curation

This subfolder contains the **dataset curation and preprocessing pipeline** for selecting representative genes from the 1,011 *Saccharomyces cerevisiae* yeast isolate genomes ([Peter et al., 2018](https://doi.org/10.1038/s41586-018-0030-5)), creating an unbiased, length-stratified benchmark spanning 50 bp to 5,000 bp.

---

## Motivation & Experimental Purpose

To rigorously test how **input sequence length affects model representations** (Hypothesis 1), evaluating only a handful of arbitrarily chosen genes introduces selection bias. 

This module algorithmically filters the thousands of coding sequences present across the 1,011 yeast genomes to construct a standardized benchmark of **100 genes with a strictly uniform length distribution**:
$$\text{Target Lengths} \in \{50, 100, 150, 200, \dots, 4950, 5000\} \text{ bp}$$

Each selected gene is conserved across all 1,011 strains, exhibiting minor single-nucleotide variations while maintaining near-constant length, providing an ideal testbed for sequence similarity and contextuality evaluations.

## Directory Organization

```
Yeast Gene Selection/
├── lengthSorter.py                # Scans all CDS genes and sorts them by sequence length
├── geneSelector.py                # Algorithmically samples 100 genes spanning 50 to 5,000 bp
├── copySelectedGenes.py           # Extracts selected gene FASTAs into the benchmark directory
├── geneCombiner.py                # Combines multi-strain FASTA records
├── verify_setup.py                # Validates dataset integrity prior to gLM inference
├── glm-inference.ipynb            # Generates embeddings across gLMs for the 100 genes
├── finalGenes.txt                 # Dictionary mapping target length to (gene_name, actual_len, delta)
├── hundredGenes.txt               # Candidate genes list for each target length bin
├── sortedGenes.txt                # Complete length-sorted index of all yeast coding genes
├── 100 Genes/                     # Benchmark directory containing 100 selected gene FASTAs (gitignored)
└── All Genes/                     # Raw repository of all extracted yeast genes (gitignored)
```

## Pipeline Execution & Script Details

```
All Yeast CDS Genes (All Genes/)
            │
            ▼
     lengthSorter.py  ────────► sortedGenes.txt (All genes indexed by length)
            │
            ▼
     geneSelector.py  ────────► finalGenes.txt (100 genes matching [50..5000] bp)
            │
            ▼
  copySelectedGenes.py ───────► 100 Genes/<GENE>_<LEN>.fasta (100 benchmark FASTAs)
            │
            ▼
     verify_setup.py  ────────► Validates 1,011 strains present per FASTA
            │
            ▼
   glm-inference.ipynb ───────► Generated embeddings for Embeddings Evaluation/
```

### 1. `lengthSorter.py`
Iterates through all coding sequences in `All Genes/`, determines the exact nucleotide length of each gene, and writes a sorted list of `(gene_name, length)` tuples to `sortedGenes.txt`.

### 2. `geneSelector.py`
Iterates through the target length range:
$$\text{seqLen} = 50, 100, 150, \dots, 5000$$
For each target length, queries `sortedGenes.txt` for candidate genes within a tolerance threshold ($|\text{length} - \text{target}| \le 20 \text{ bp}$). It selects the gene minimizing distance to the target length and writes the mapping to `finalGenes.txt`.

### 3. `copySelectedGenes.py`
Reads `finalGenes.txt`, locates each selected gene's multi-strain FASTA in `All Genes/`, and copies it to `100 Genes/` with the standardized naming convention:
`<GENE>_<ACTUAL_LENGTH>.fasta` (e.g., `YAL015C_1200.fasta`, `YBL003C_399.fasta`).

### 4. `verify_setup.py`
Performs automated pre-inference quality checks:
- Verifies that `100 Genes/` contains all expected FASTA files.
- Confirms that each FASTA contains exactly 1,011 sequence records (one per strain).
- Validates that sequences contain valid IUPAC nucleotide characters (`A, C, G, T, N`).

### 5. `glm-inference.ipynb`
Jupyter notebook running batch inference across foundation gLMs for all 100 genes, feeding the resulting representations directly into `Embeddings Evaluation/100 Genes/`.

## Execution Instructions

To reproduce the benchmark gene curation pipeline from scratch:
```bash
# Step 1: Sort all available yeast genes by length
python "Yeast Gene Selection/lengthSorter.py"

# Step 2: Select the 100 benchmark genes
python "Yeast Gene Selection/geneSelector.py"

# Step 3: Copy and standardize FASTA files into 100 Genes/
python "Yeast Gene Selection/copySelectedGenes.py"

# Step 4: Verify dataset completeness and strain count
python "Yeast Gene Selection/verify_setup.py"
```
